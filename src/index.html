Golden hue HSL hue rotation by the golden angle

Rotates hue by approximately 137.5° per step, preserving saturation and lightness. Use steps here; --colour-adjust-hue() takes degrees directly. Zero keeps the hue; negative steps rotate backwards.

Scale saturation HSL saturation, 1 is unchanged

Named colours

Optional. Define your own --colour() after the library (this page mirrors examples/named.css). Names then work in any helper. var(--primary) reads a CSS custom property; the identifier primary is resolved by --colour(). These named samples stay fixed while the Playground selection changes.

@function --colour(
  --value type(<custom-ident> | <color>): currentColor
) returns <color> {
  result: if(
    style(--value: primary): #6750a4;
    style(--value: secondary): #03dac6;
    style(--value: success): #22c55e;
    style(--value: danger): #ef4444;
    else: var(--value)
  );
}

.swatch { background: --colour(primary); }
.alert  { background: --colour-tint(85%, danger); }
/* Helpers resolve names too: --colour() is optional here. */
.related { background: --colour-golden(1, --colour(primary)); }
.support { background: --colour-scale-saturation(0.4, primary); }

Composition

Build a three-colour palette from one starting colour. Start with orange (#FFA500), or choose another Playground colour to update the whole example.

With φ ≈ 1.618, the golden angle is 360 × (1 − 1/φ) ≈ 137.507764°. Keep the base as Primary, rotate it once for Secondary, and return to the original base for Supporting at 0.4 times its saturation.

Make room for your next idea

A primary accent, a secondary action, and supporting borders and surfaces — all from one colour.

The swatches show the unadjusted palette. Hue rotation preserves saturation and lightness: the reel’s darker teal also reduces lightness. Here, --colour-tone() sets the button’s secondary colour to 35% OKLCH lightness in light mode and 80% in dark mode.

--colour-contrast() chooses black or white text. Golden-angle spacing does not guarantee WCAG compliance; check the final text, backgrounds and UI states.

.stage {
  --base: var(--active); /* Playground selection */
  --primary: var(--base);
  --secondary: --colour-golden(1, var(--base));
  --supporting: --colour-scale-saturation(0.4, var(--base));
  background: light-dark(
    --colour-tint(85%, var(--supporting)),
    --colour-shade(90%, var(--supporting))
  );
  color: light-dark(#18212b, #e8edf2);
}
.palette-primary { background: var(--primary); }
.palette-secondary { background: var(--secondary); }
.palette-supporting { background: var(--supporting); }
.card {
  --surface: light-dark(
    --colour-tint(95%, var(--supporting)),
    --colour-shade(80%, var(--supporting))
  );
  background: var(--surface);
  color: light-dark(#000, #fff);
  color: --colour-contrast(var(--surface));
  border: 2px solid var(--supporting);
}
.card-accent {
  background: var(--primary);
  color: var(--on-active); /* Playground fallback */
  color: --colour-contrast(var(--primary));
}
.button {
  --background: light-dark(
    --colour-tone(35%, var(--secondary)),
    --colour-tone(80%, var(--secondary))
  );
  background: var(--background);
  color: light-dark(#fff, #000);
  color: --colour-contrast(var(--background));
  border-color: var(--supporting);
}
