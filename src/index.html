02 / Colour operations

Every manipulation, demonstrated.

All nine transformation helpers run against the active colour you selected above.

HSL · sRGB · alpha

04 / Putting it together

In real components.

Copy a function into any CSS property that accepts a colour.

A familiar API. Native implementation.

The helpers delegate to a single palette function. Change the active swatch above and this whole component updates.

.card {
  background: --colour-tint(blue, 90%);
  border-color: --colour(blue);
}

.card:hover {
  background: --colour-lighten(blue, 12);
}

.overlay {
  background: --colour-opacity(black, .5);
}

Every colour has an entire system.
