02 / Colour operations

Every manipulation, demonstrated.

All nine transformation helpers run against the active colour you selected above.

HSL · sRGB · alpha

Lighten

HSL lightness +20 points

--colour-lighten(20, var(--active))

Darken

HSL lightness −20 points

--colour-darken(20, var(--active))

Saturate

Increase HSL saturation

--colour-saturate(30, var(--active))

Desaturate

Reduce HSL saturation

--colour-desaturate(45, var(--active))

Adjust hue

Rotate hue by 90 degrees

--colour-adjust-hue(90, var(--active))

Tint

Blend 42% white in sRGB

--colour-tint(42%, var(--active))

Shade

Blend 38% black in sRGB

--colour-shade(38%, var(--active))

RGBA

Apply an alpha of 0.4

--colour-rgba(0.4, var(--active))

Opacity

RGBA convenience alias

--colour-opacity(0.6, var(--active))

04 / Functional composition

Nest anything. No intermediary variables.

Amount first, colour last. Omit the colour to use currentColor, or pass any CSS colour, including another function's result.

Inherited color for the currentColor examples:

Implicit currentColor

No colour argument: lightens the inherited text colour.

Implicit opacity

Half-transparent inherited colour.

--colour-opacity(0.5)

Palette colour

Named entries resolve through --colour().

--colour-darken(15, blue)

Hex colour

Any CSS colour passes straight through.

--colour-shade(30%, #6750a4)

OKLCH colour

Modern colour spaces work too.

--colour-tint(25%, oklch(60% 0.2 250))

Custom property

--brand is set to --colour(teal) on this page.

--colour-lighten(10, var(--brand))

Custom property fallback

An undefined property falls back to rgb().

--colour-desaturate(
  40,
  var(--undefined-brand, rgb(255, 87, 34))
)

Two nested transformations

Lighten, then make translucent.

--colour-opacity(
  0.8,
  --colour-lighten(15, blue)
)

Three nested transformations

Darken, saturate, then apply opacity.

--colour-opacity(
  0.8,
  --colour-saturate(
    20,
    --colour-darken(10, blue)
  )
)

Four levels, nested commas

A color-mix() of two palette colours, tinted, accented and rotated.

--colour-adjust-hue(
  30,
  --colour-accent(
    700,
    --colour-tint(
      10%,
      color-mix(in srgb, --colour(red), --colour(amber) 40%)
    )
  )
)

05 / Putting it together

In real components.

Copy a function into any CSS property that accepts a colour.

A familiar API. Native implementation.

The helpers delegate to a single palette function. Change the active swatch above and this whole component updates.

.card {
  color: --colour(blue);
  background: --colour-tint(90%);
  border-color: --colour();
}

.card:hover {
  background: --colour-lighten(12, blue);
}

.overlay {
  background: --colour-opacity(.5, black);
}

Every colour has an entire system.

The demo itself uses function calls, not hard-coded swatches. Tint, base, and shade together produce the tonal grouping below.
