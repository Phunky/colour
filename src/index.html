Composition

Every function returns a colour and accepts one, so a whole component can come from a single expression.

Colour scheme

Upgrade your plan

Background, text, border and hover colours all derive from the CSS shown here.

.card {
  --surface: light-dark(
    --colour(white),
    --colour-tone(25%, blue-grey)
  );
  background: var(--surface);
  color: --colour-contrast(var(--surface));
}

.button {
  --background: --colour-tone(
    65%,
    --colour-mix(35%, blue, purple)
  );
  background: var(--background);
  color: --colour-contrast(var(--background));
  border-color: --colour-darken(15, var(--background));
  &:hover {
    background: --colour-darken(
      10,
      var(--background)
    );
  }
}

Get started

1. Add the stylesheet

Copy src/colour.css into your project.

<link rel="stylesheet" href="colour.css">

2. Use the functions

Anywhere CSS accepts a colour.

.button {
  background: --colour(blue);
  color: --colour-contrast(blue);
}

3. Check browser support

Native CSS functions need Chrome or Edge 139+. This page also ships a build-time compiled version for Safari and Firefox.

Functions

--colour(c)
Palette colour by name; any CSS colour passes through
--colour-lighten(n, c) --colour-darken(n, c)
HSL lightness ± n points
--colour-saturate(n, c) --colour-desaturate(n, c)
HSL saturation ± n points
--colour-adjust-hue(deg, c)
Rotate the hue
--colour-tint(%, c) --colour-shade(%, c)
Mix with white or black
--colour-tone(%, c)
Set OKLCH lightness
--colour-chroma(×, c)
Scale OKLCH chroma
--colour-mix(%, c1, c2)
Mix two colours in OKLCH
--colour-opacity(α, c) --colour-fade(×, c)
Set or multiply alpha
--colour-accent(level, c)
Material-style shade, 50–1000
--colour-contrast(bg)
Black or white text for a background

c is optional and defaults to currentColor, except in --colour-mix() and --colour-contrast(). The README has the full API, browser support and more examples.
